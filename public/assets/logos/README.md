# Logo Files

Place the following logo files in this directory:

- **obmh-en.png** - English version of the Ottawa Black Mental Health Coalition logo
- **obmh-fr.png** - French version (SMNO) of the Ottawa Black Mental Health Coalition logo

The website will automatically switch between these logos based on the user's language preference.

## Logo Requirements

- Format: PNG with transparent background
- Recommended size: 512x512px or larger
- Aspect ratio: Square or circular
