These images will be displayed in the "Community Moments" carousel section.

## Image Requirements

- Format: JPG or JPEG
- Recommended size: 1920x1080px or larger (16:9 aspect ratio preferred)
- File size: Optimized for web (< 500KB each recommended)
- Content: Community event photos, people connecting, mental health moments
- All images will be displayed at the same size regardless of original dimensions
