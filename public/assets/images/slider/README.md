# Slider Images

Place 6 event images in this directory with the following names:

- 1.jpg
- 2.jpg
- 3.jpg
- 4.jpg
- 5.jpg
- 6.jpg

These images will be used in the auto-rotating carousel above the footer.

## Image Requirements

- Format: JPG or JPEG
- Recommended size: 1920x1080px (16:9 aspect ratio)
- File size: Optimized for web (< 500KB each)
- Content: Event photos, community images, or relevant visuals
